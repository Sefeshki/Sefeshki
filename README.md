## `whoami`

Hey, I'm **Sefeshki**.

Used to be a grey hat. These days, I'm retired from that chapter.

Now I spend my time building random projects, experimenting with ideas, and creating repositories that I genuinely hope someone finds useful.

I don't necessarily build things because they need to exist. Sometimes I just have an idea and decide to make it real.

- Former grey-hat enthusiast.
- Independent developer and project builder.
- Linux enthusiast.
- Interested in software, automation and technology.
- Currently building **VANTA**.
